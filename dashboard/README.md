## Dashboard Information

- The [`images`](https://github.com/worleyek/insurance-claims-risk-model/tree/main/dashboard/images) folder contains screenshots of the completed Power BI dashboard.
- The [`power-bi-files`](https://github.com/worleyek/insurance-claims-risk-model/tree/main/dashboard/power-bi-files) folder contains the Power BI project files (.pbip) as well as a compressed archive (`insurance_claims_analysis_dashboard.zip`) that includes the Power BI project files.
- The [`dashboard-data`](https://github.com/worleyek/insurance-claims-risk-model/tree/main/dashboard/dashboard-data) folder contains the datasets used to build the dashboard:
  - `claims_predictions.csv` (as a .zip file due to large file size)
  - `feature_importances.csv`
  - `model_results.csv`

  These files were generated from the machine learning workflow in insurance_claim_modeling.ipynb and imported into Power BI to create the dashboard visualizations.
